## Sobre mí

Ingeniero en Sistemas Computacionales con especialidad en **Desarrollo de Software**. Enfocado en diseñar **arquitecturas limpias, persistencia de datos confiable y soluciones prácticas** en backend, aplicaciones full stack, móvil, escritorio e integración de **LLMs e IA aplicada**.

- **Backend & Arquitectura:** APIs REST, diseño relacional (PostgreSQL / SQLite / Supabase), autenticación, Row Level Security y entornos estandarizados con Docker.
- **Full Stack & Multiplataforma:** React, Next.js, React Native (Expo) y Electron con enfoque en experiencia de usuario real.
- **IA Aplicada:** Pipelines con Gemini / OpenAI / DeepSeek, salidas estructuradas en JSON validado, análisis multimodal y automatización.
